# Переключение домена gpn-oil.uz на GitHub Pages

## Что сейчас

DNS домена держит Billur (`ns1.billur.com` … `ns4.billur.com`) — менять записи
надо в его панели, не в GitHub.

| Запись | Значение сейчас | Что с ней делаем |
|---|---|---|
| `A` @ | `176.57.64.226` | **заменить** на четыре адреса GitHub |
| `AAAA` @ | нет | **добавить** четыре адреса GitHub (необязательно, но лучше) |
| `CNAME` www | `gpn-oil.uz` | оставить как есть |
| `MX` @ | `10 mail.gpn-oil.uz` | **не трогать** |
| `A` mail | `176.57.64.226` | **не трогать** |
| `TXT` @ | `v=spf1 +a +mx -all` | **поправить**, см. ниже |

Сайт сейчас стоит за DDoS-Guard (`176.57.64.226` — его прокси). После переезда
защита уйдёт: для статики это не проблема, но знать стоит.

## Ловушка с почтой

На домене работает почта: `MX` ведёт на `mail.gpn-oil.uz`, а тот — на тот же
`176.57.64.226`.

Сама почта переезда не заметит: у `mail` своя A-запись, её мы не трогаем.
А вот SPF заметит. Сейчас в нём стоит `+a` — «письма имеет право слать хост
из A-записи домена». Как только A-запись станет адресами GitHub, SPF начнёт
разрешать отправку с GitHub (бессмысленно) и **перестанет** разрешать
почтовому серверу. Письма с домена поедут в спам.

Поэтому одновременно с A-записью меняем TXT:

```
было:  v=spf1 +a +mx -all
стало: v=spf1 +mx -all
```

`+mx` разрешает отправку с хоста из MX-записи — это и есть почтовый сервер,
так что ничего не теряется.

## Как посмотреть сайт до переключения

Адрес `zvezdotank.github.io/gpn-oil.uz` для проверки не годится: из-за файла
`CNAME` в репозитории GitHub отвечает на него редиректом `301` на `gpn-oil.uz`,
а там пока старый сайт. Убрать `CNAME` тоже не выход — сайт собран на
абсолютных путях (`/site.css`, `/img/…`, `/industrial`), и в подпапке
`github.io/gpn-oil.uz/` они все ведут в никуда.

Правильный способ — временный поддомен. Живому сайту он ничем не грозит:
это отдельная запись, апекс-домен не трогается.

**1.** В панели Billur добавить одну запись:

```
CNAME   new   zvezdotank.github.io.
```

**2.** В файле `CNAME` репозитория уже стоит `new.gpn-oil.uz` — GitHub сам
подхватит его и выпустит сертификат.

**3.** Открыть `https://new.gpn-oil.uz` и проверить всё по-настоящему:
адреса без `.html`, страницу 404, заглушки-редиректы, HTTPS.

Индексации бояться не нужно: на всех страницах `canonical` жёстко указывает
на `https://gpn-oil.uz/…`, поэтому поисковик не примет копию за отдельный сайт.

Когда всё проверено — верните в файле `CNAME` значение `gpn-oil.uz`,
запушьте и переключайте записи по инструкции ниже. Запись `new` после
переезда можно удалить.

## Порядок

**За сутки до переезда — снизить TTL.** Сейчас у A-записи TTL около 14 часов:
пока он не истечёт у провайдеров, откат будет таким же долгим. Поставьте
у A-записи TTL `300` и подождите старые 14 часов. Этот шаг не меняет ничего
на сайте, но превращает откат из «полдня» в «пять минут».

**1. Поднять Pages.** В репозитории Settings → Pages → Source: `Deploy from
a branch`, Branch: `main`, папка `/ (root)` → Save. Через минуту сайт будет
на `zvezdotank.github.io/gpn-oil.uz` — откройте и проверьте, что всё на месте.

**2. Развернуть приёмник заявок.** Пока воркер не настроен, формы никуда
не отправляют. Инструкция в `relay/README.md`, всё делается в браузере.
Переключать домен раньше нельзя — заявки будут теряться.

**3. Поменять записи в панели Billur:**

```
A     @    185.199.108.153
A     @    185.199.109.153
A     @    185.199.110.153
A     @    185.199.111.153

AAAA  @    2606:50c0:8000::153
AAAA  @    2606:50c0:8001::153
AAAA  @    2606:50c0:8002::153
AAAA  @    2606:50c0:8003::153

TXT   @    v=spf1 +mx -all
```

Старую `A 176.57.64.226` для `@` удалить. Записи `MX`, `A mail` и `CNAME www`
не трогать.

**4. Включить HTTPS.** В Settings → Pages поле Custom domain должно уже
показывать `gpn-oil.uz` — он берётся из файла `CNAME` в репозитории. Дождитесь
зелёной галочки проверки DNS (обычно минуты, иногда до получаса), потом
поставьте галочку **Enforce HTTPS**. Сертификат выпускается автоматически;
пока он выпускается, сайт может отдавать предупреждение — это нормально
и проходит само.

## Проверка

```bash
dig +short A gpn-oil.uz
```

Должны быть четыре адреса `185.199.10*.153`. Дальше:

```bash
curl -sI https://gpn-oil.uz/ | head -3
```

Ожидаем `HTTP/2 200` и в заголовках `server: GitHub.com`. И проверьте вручную
несколько адресов: `/industrial`, `/uz/`, `/podbor`, `/page57584865.html`
(должен увести на `/gpn`) и любой несуществующий — он обязан показать
нашу страницу 404, а не гитхабовскую.

## Откат

Вернуть в панели одну запись `A @ 176.57.64.226`, удалить AAAA, вернуть SPF
на `v=spf1 +a +mx -all`. Со сниженным TTL это подействует за пять минут.
Старый сайт на Tilda никуда не девается — его нужно оставить нетронутым,
пока новый не отработает хотя бы неделю.

## Через неделю после переезда

- В Яндекс.Вебмастере и Google Search Console отправить `sitemap.xml`
  и проверить, что старые адреса не выпали из индекса.
- Проверить, что заявки с форм доходят.
- Проверить, что письма с домена не уезжают в спам (после правки SPF).
