# Приёмник заявок

Между сайтом и телеграм-группой стоит маленький посредник: сайт отправляет
обычную HTML-форму, посредник пересылает её ботом в группу и возвращает
человека на `spasibo.html`. Токен бота хранится у посредника в шифрованных
переменных и в репозиторий никогда не попадает.

Почему не напрямую из браузера: статику отдаёт хостинг как есть, исходник
страницы видит любой. Токен в коде страницы = любой желающий шлёт сообщения
в группу от имени бота.

## Настройка — всё в браузере, терминал не нужен

**1. Бот.** В телеграме напишите @BotFather → `/newbot` → имя → получите токен
вида `1234567890:AAH…`. Скопируйте целиком, вместе с цифрами до двоеточия.

**2. Группа или канал.** Добавьте туда бота и менеджеров, напишите любое
сообщение. Для **канала** бота обязательно сделать администратором с правом
публикации — иначе телеграм не покажет канал на шаге 5, и ID взять будет
неоткуда.

**3. Посредник.** dash.cloudflare.com → Compute (Workers) → Create →
Start with Hello World. **Имя воркера должно быть `gpn-relay`** — под этим
адресом формы на сайте уже настроены. Deploy, затем Edit code: удалите
содержимое и вставьте целиком `worker.js` из этой папки → Deploy.

**4. Секреты.** В воркере: Settings → Variables and Secrets → Add.
Добавьте две штуки, тип Secret (не Text):

| Имя | Значение |
|-----|----------|
| `BOT_TOKEN` | токен из шага 1 |
| `CHAT_ID` | заполняется на шаге 5 |

Сначала добавьте только `BOT_TOKEN` и сохраните.

**5. ID группы или канала.** Откройте адрес воркера с `/setup` на конце —
страница покажет список чатов. Нужный ID будет с минусом: `-1001234567890`.
Добавьте его секретом `CHAT_ID`.

Если список пуст: бот не видит чат. Для канала проверьте, что он
администратор, и опубликуйте там любое сообщение, потом обновите страницу.

После этого `/setup` отключается сам — он работает, только пока `CHAT_ID` пуст.

**6. Адрес.** Воркер отвечает на `https://relay.gpn-oil.uz/` — это собственный
адрес на домене сайта, привязанный в воркере через Domains → Add Domain.
Формы на всех страницах уже отправляют туда.

Так сделано намеренно: имя самого воркера в Cloudflare может быть любым
(у нас оно автоматическое, `silent-math-2fd3`), и если воркер придётся
пересоздать, адрес не изменится и сайт править не потребуется.

## Проверка

Отправьте заявку с сайта. В группу должно прийти сообщение, а браузер —
перекинуть на страницу «Спасибо, приняли». Если сообщения нет, откройте
в воркере Logs: там видно, что ответил телеграм.
